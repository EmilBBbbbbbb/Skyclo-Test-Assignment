# Консольная утилита расчёта авансов и взаиморасчётов по договорам

Консольная утилита для финансового учёта расчётов с подрядчиками по договорам, отдельным работам и платежам на заданную дату среза (по умолчанию: `10.11.2026`).

Проект выполнен в строгом соответствии с конституцией проекта:
- **Язык**: Python 3.11+ (только стандартная библиотека: `csv`, `decimal`, `datetime`, `argparse`, `pathlib`, `unittest`).
- **Зависимости**: **0 внешних зависимостей** — запуск работает из коробки без `pip install` и виртуальных окружений.
- **Работа с деньгами**: **Строго без float**. Все суммы и расчёты ведутся в `decimal.Decimal` с точностью до копейки (`0.01`).
- **Архитектура**: Никаких баз данных, Docker или веб-серверов.

---

## Быстрый запуск в одну команду

Для генерации отчёта на контрольную дату `10.11.2026` выполните из корня репозитория:

```bash
python report.py
```

### Запуск тестов

Все расчёты и краевые случаи (авансы без привязки к работе, возвраты, очереди, отменённые работы, фильтрация по датам) покрыты unit-тестами:

```bash
python -m unittest discover tests -v
```

---

## Дополнительные параметры запуска

```bash
# Срез на произвольную дату:
python report.py --date 2026-10-15

# Экспорт отчёта в формате CSV (для открытия в Excel / Таблицах):
python report.py --format csv > report_2026-11-10.csv

# Указание нестандартной папки с данными:
python report.py --data-dir ./data --date 2026-11-10
```

## Обязательные отчётные артефакты

1. **[report.py](report.py)** — исполняемый CLI-скрипт отчёта.
2. **[DECISIONS.md](DECISIONS.md)** — подробный журнал всех 5 принятых решений и допущений по данным в стандартизированном формате: *что решали -> варианты -> что выбрали и почему -> что изменится при другом выборе*.
3. **[NOTE_FOR_ACCOUNTANT.md](NOTE_FOR_ACCOUNTANT.md)** — записка бухгалтеру (ровно 8 строк) простым человеческим языком без технического жаргона: как читать отчёт и что подтвердить после выхода из отпуска.
4. **[README.md](README.md)** — данная инструкция.

## Структура проекта

```text
.
├── report.py             # Точка входа CLI (argparse, обработка ошибок, запуск пайплайна)
├── src/
│   ├── __init__.py
│   ├── models.py         # Модели данных (Contract, Work, Payment, WorkSettlement, ContractSettlement)
│   ├── loader.py         # Загрузка и валидация CSV-файлов, дат (YYYY-MM-DD) и Decimal
│   ├── calculator.py     # Исторический срез на дату, приоритет прямых оплат и FIFO-распределение авансов
│   └── formatter.py      # Вывод форматированной таблицы в консоль и CSV
├── tests/
│   ├── __init__.py
│   ├── test_loader.py    # Тесты загрузки и валидации CSV
│   └── test_calculator.py# Тесты финансовой математики, очередей, возвратов, отмен и дат
├── data/                 # Исходные файлы выгрузки
│   ├── contracts.csv     # Договоры
│   ├── works.csv         # Работы по договорам
│   ├── payments.csv      # Платежи
│   └── FORMAT.md         # Описание формата
├── DECISIONS.md          # Журнал допущений по данным
├── NOTE_FOR_ACCOUNTANT.md# Записка бухгалтеру
└── README.md             # Инструкция по запуску
```
